Agentic kdb+/q Trading System

Repo →

kdb+/q · MCP (Model Context Protocol) · Python · extends KX Systems' official server

Problem. Manually tuning a trading strategy's parameters is slow and unprincipled — and most "autonomous agent" demos never get tested past the happy path, so no one actually knows whether the agent reasons correctly when a strategy fails or the infrastructure breaks.

Approach. Forked KX Systems' production kdb-x-mcp-server and added 6 tools (list_strategies, get_price_data, run_q_analytics, run_backtest, get_run_history, compare_runs), wiring them to my own backtesting-engine as a local editable dependency. The tools let an LLM agent query kdb+ price data, run native q analytics, execute lookahead-safe backtests, and log/compare every run by session — everything it needs to design, test, and iterate on a strategy end to end.

6New MCP tools
5+1Validated test runs

Across 5 controlled tests and 1 real-world run: found genuine Pareto-improving configs via non-monotonic search; correctly reported zero valid runs (instead of a misleading "best") when no config met a drawdown constraint, and explained why; correctly diagnosed a real infrastructure fault — stale q session state — instead of hallucinating a result. A stopping-rule bug (narrated vs. explicit counter state) was caught and fixed mid-testing.

Why it matters here. kdb+/q is the time-series database standard on real trading desks. This shows I can extend a real vendor's production codebase and wire an agent to genuine market-data infrastructure — and, more importantly for a research role, that I design validation tests meant to break the system rather than just demo the happy path.

Single-Camera 3D Object Measurement

Capgemini · Feb–Mar 2026

OpenCV · Camera calibration · PnP · Projective geometry

Problem. Estimate a real object's length, breadth, and height from a single uncalibrated consumer camera — no depth sensor, no learned depth model.

Approach. After testing and setting aside COLMAP/Structure-from-Motion, shape-from-shading, NeRF, and monocular depth models (MiDaS, DepthAnything) — each unstable or infeasible for the constraints — landed on a deterministic geometry pipeline: camera calibration, an ArUco floor marker for world scale, PnP pose estimation, and ray–plane intersection for metric measurement from a single frame.

88.89%Measurement accuracy
1.31RMSE

Why it matters. Same instinct quant/market-data roles need: convert a noisy real-world measurement into a calibrated, verifiable number, and be able to explain exactly why each simpler approach was rejected.
